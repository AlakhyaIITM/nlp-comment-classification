# Dataset Files

The original Kaggle dataset is split into multiple CSV files so that each file remains below GitHub's browser upload limit.

## Training Data

The complete training dataset contains 198,000 rows across:

- `train_part_1.csv`
- `train_part_2.csv`
- `train_part_3.csv`
- `train_part_4.csv`

## Test Data

The complete test dataset contains 102,000 rows across:

- `test_part_1.csv`
- `test_part_2.csv`

`Sample.csv` contains the Kaggle submission format.

The split files preserve the original rows and columns; they are only divided into smaller CSV files for repository storage.
